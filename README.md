# Holovision

Rip real Pokémon TCG booster packs with USDC on BNB Chain. See the odds before you open, then ship your cards home or sell them back instantly.

```bash
npm install
npm run dev            # http://localhost:3000
node scripts/build-catalog.mjs   # refresh card data, prices and images (needs ffmpeg)
```

Demo build: purchases, draws and buybacks are simulated client-side. See `AGENTS.md` for structure and conventions.
